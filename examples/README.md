# Examples

What a populated harness looks like, for a **fictional** channel. Nothing here
is data: the channel, the creator, the videos and every figure are invented to
show the shape of each file.

**The agent never reads this folder as memory.** Its memory is `memory/`,
which starts empty on purpose and is filled from real tool outputs. Copying
these files into `memory/` would give the agent a channel that does not exist.

| File | What it shows |
|---|---|
| [`memory/strategy.md`](memory/strategy.md) | A strategy at stage `market-validated`, each audience line marked measured or hypothesis |
| [`memory/voice_profile.md`](memory/voice_profile.md) | A voice built from verbatim quotes, not adjectives |
| [`memory/rules.md`](memory/rules.md) | One rule the creator imposed, with its date and data |
| [`memory/coach_preferences.md`](memory/coach_preferences.md) | Preferences learned from corrections |
| [`memory/conversation_journal.md`](memory/conversation_journal.md) | A prediction, the outcome, and what it taught — including a miss |

Video IDs are written as `VIDEO_A`, `VIDEO_B`… so none of them can be mistaken
for a real link.

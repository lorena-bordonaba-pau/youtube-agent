# SOP — distilled procedures

An SOP is not written by hand: it is **extracted** by analysing real material,
which is why this folder starts empty.

| File | What it is | Who generates it |
|---|---|---|
| `scripting_sop.md` | Your script formula: beats, hooks, retention devices | Analysing transcripts of your best-retaining videos |
| `niche_bend_sop.md` | Your content pillars and the framework for adapting topics | The `identidad-canal` skill, from a reference channel |
| `premisa_sop.md` | Your premise template, used before recording | Distilled after several videos |

**Every SOP should start with `Generated: YYYY-MM-DD`.** After 60 days it is
worth refreshing: a channel that evolves leaves its own formula behind.

When `scripting_sop.md` exists it has **structural primacy** over whatever the
`guion` skill would do by default. That is the difference between a script that
is yours and one that is correct but nobody's.

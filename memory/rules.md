**EMPTY, and that is how it should start.**

Only restrictions you impose explicitly go here, with a date and with the data
that backs them where there is any. Example format:

```
**2026-01-15 — No videos shorter than 8 minutes.**
Already decided, not a goal. Supporting data: [the figures you measured, and
the tool that produced them].
How to apply it: [what the agent should stop proposing, specifically].
```

**The agent never fills this file in on its own initiative.** A rule you did
not ask for is not a rule: it is the model deciding for you.
